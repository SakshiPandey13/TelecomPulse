# IBM Telco Customer Churn Prediction

## 1. Project Overview
This project aims to analyze customer churn in the telecommunications industry and develop machine learning models to predict whether a customer is likely to leave a service provider.

Customer churn is an important business problem because losing customers can affect revenue and long-term growth.

## 2. Problem Statement
Telecommunications companies need to identify factors associated with customer churn and use historical customer data to help improve customer retention.

## 3. Project Objectives
1. Analyze customer churn patterns.
2. Investigate the relationship between contract type, tenure, and churn.
3. Examine customer charges and subscribed services.
4. Implement and compare four classification algorithms.
5. Identify important predictive factors and recommend customer-retention strategies.

## 4. Dataset
**Dataset:** IBM Telco Customer Churn

**Source:** https://www.kaggle.com/datasets/blastchar/telco-customer-churn?resource=download

The dataset will be inspected to verify its dimensions, columns, missing values, duplicate records, and data types before preprocessing.

## 6. Machine Learning Models
The planned classification models are:
1. Logistic Regression
2. Decision Tree
3. Random Forest
4. K-Nearest Neighbors (KNN)

## 7. Evaluation Metrics
Accuracy, precision, recall, F1-score, macro F1-score, balanced accuracy, and confusion matrices will be used as appropriate.

The final model will be selected based on actual evaluation results.
